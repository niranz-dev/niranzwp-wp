# Security policy

## Reporting

Please report vulnerabilities privately, before disclosing them publicly:

- **security@niranz.dev**, or
- GitHub's [private advisory form](https://github.com/niranz-dev/niranzwp-wp/security/advisories/new)

Include what you did, what happened, and what you expected. A proof of concept
helps but is not required. You will get an acknowledgement within 72 hours.

## Scope

This plugin registers abilities that let an authenticated administrator work on
their own site, and an OAuth 2.0 device-grant server that issues the credential
for it. Both are in scope, as are the admin screens.

Reports that require an attacker to already hold administrator credentials, or
to have filesystem access to the server, are generally not vulnerabilities in
this plugin — but send them anyway if you are unsure.

## Supported versions

The latest release. This is a young project; please update before reporting.
